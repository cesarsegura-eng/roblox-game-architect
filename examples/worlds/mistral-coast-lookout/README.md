# Mistral Coast Lookout

A hand-authored Scene Recipe v1 compatibility blockout for `apps/blender-addon`. It combines a
windy coastal headland, a small timber lookout with a sparse interior, a path,
rocky shoreline, and a distant beacon. The scene is intentionally modular and
low detail so the player route and building silhouette are easy to change.

## Use

In Blender, install the extension described in
[`apps/blender-addon`](../../../apps/blender-addon/README.md), open the **RGA**
sidebar, and import `scene-recipe.json`. The add-on places all recipe content in
a separate collection. Select the scene objects and export GLB for review in
Roblox Studio's Importer.

This sample demonstrates the data exchange and visual blockout only. It has no
sculpted terrain, custom UVs, sound, fog, collision tuning, or game logic. It was
written by hand and is not output from the LLM world-design agent.
